### Variable Scope:<br/>
A variable may belong one of the following scopes:<br/>
- Global Scope: It is the default scope for all code running in script mode.<br/>
- Module Scope: The scope for code running in module scope.<br/>
- Function Scope: The scope created with a function.<br/>
<br/>
<strong>Note</strong><br/>
Let and Const can belong to an additional scope named Block Scope which is the scope created with a <strong> pair of curly braces </strong>named <strong> a block</strong>.<br/>
<br/>
If you <strong>declare a variable outside any function, it is called a Global Variable</strong>. This global variable is available to any other code in the current document.<br/><br/>
If you <strong>declare a variable within a function, it is called local variable and it is only available within the function.</strong>.<br/>

<strong> Note:</strong><br/>
The variables declared with Const and Let only live inside the { }
where they were born. In case you need it out , they should be declared outside { } from the start.<br/>
